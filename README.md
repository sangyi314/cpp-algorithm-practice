A personal repository for:

- Modern C++ algorithm practice
- Coding test preparation

- Technical interview preparation

## Goals

- Improve algorithmic problem-solving skills
- Become familiar with common coding-test patterns
- Practice implementing algorithms with modern C++
- Improve time and space complexity analysis
- Improve coding speed under time constraints
- Build systematic experience with common data structures and algorithms

## Environment

- C++23
- GCC / G++
- Visual Studio Code
- Git
- GitHub

## Repository Structure

```text
cpp-algorithm-practice/
├── 01-array-string/
├── 02-hash-two-pointers-sliding-window/
├── 03-prefix-sum-binary-search-stack-queue/
├── 04-dfs-bfs-backtracking/
├── 05-greedy-dynamic-programming/
└── mock-exams/
```

- Each directory corresponds to a main algorithm training stage.
- `.cpp` files store personal solutions.
- README files record the algorithms and notes covered by each topic.
- `mock-exams` is used for complete timed simulations.
